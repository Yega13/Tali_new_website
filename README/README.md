# Tali Golergant - Official Website

![Tali Golergant](screenshots/hero-preview.png)

The official website for **Tali Golergant** - Singer, Songwriter, and Artist from Luxembourg. Eurovision 2025 representative.

## Live Site

**[taligolergant.com](https://taligolergant.com)**

## Tech Stack

- **React 18** - UI framework
- **Vite** - Build tool
- **Framer Motion** - Animations
- **React Router** - Navigation
- **CSS Variables** - Theming (dark/light mode)

## Features

- Responsive design (mobile-first)
- Dark/Light theme with smooth transitions
- Lazy-loaded images and videos
- SEO optimized with structured data
- Code splitting for performance

## Pages

| Page | Description |
|------|-------------|
| Home | Hero section, explore cards, social links |
| About | Bio, life journey timeline, acting videos, resume |
| Music | Music videos, Spotify player, show history |
| Gallery | Photo gallery with lightbox, organized by sections |
| News | Latest updates, interviews, announcements |
| Collaborations | Featured projects and partnerships |
| Contact | Contact form, newsletter signup, location |

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Project Structure

```
src/
├── components/     # Reusable components
│   ├── common/     # Shared components (Header, Footer, etc.)
│   └── layout/     # Layout components
├── pages/          # Page components
├── hooks/          # Custom React hooks
├── styles/         # Global styles and variables
├── constants/      # Static data
└── data/           # Content data
```

## Environment

No environment variables required for basic development.
