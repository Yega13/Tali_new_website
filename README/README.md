# Tali Golergant - Official Website

![Tali Golergant](screenshots/hero-preview.png)

The official website for **Tali Golergant** - Singer, Songwriter, and Artist from Luxembourg. Eurovision 2025 representative.

## Live Site

**[tali-new-website.pages.dev](https://tali-new-website.pages.dev)**

---

## Website Overview

This is a fully custom-built, professional designed to showcase Tali's music, performances, and journey. Every detail was crafted with care—from smooth animations to responsive layouts that work beautifully on any device.

---

## Design Philosophy

- **Modern & Premium** – Sleek dark/light themes with gold and green accents
- **Mobile-First** – Every page looks perfect on phones, tablets, and desktops
- **Smooth Animations** – Page transitions, hover effects, and micro-interactions
- **Performance Optimized** – Fast loading with lazy-loaded images and code splitting

---

## Pages & Features

### Home Page
- **Hero Section** – Full-screen background image with animated title
- **Theme Toggle** – Switch between light (green accent) and dark (gold accent) modes
- **Explore Cards** – Beautiful cards linking to Music, Gallery, About, News, Collaborations, and Contact
- **"Swipe to Explore"** – Animated arrow prompting users to scroll
- **Social Links** – Instagram, TikTok, YouTube, Facebook, Spotify

- **Timeline** – Interactive life journey with key milestones

- **Music Videos Grid** – YouTube embeds of official music videos

## Special Features

### Theme System
- **Light Mode** – White background, green primary accent (#1B8754)
- **Dark Mode** – Midnight background, warm gold accent (#D4AF37)
- **Smooth Transitions** – Colors animate when switching themes
- **Persistent Preference** – Remembers your theme choice

### Preloader Animation
- **Elegant Entry** – "Tali Golergant" text animates in on first visit
- **Session Memory** – Only shows once per browsing session
- **Smooth Fade Out** – Seamless transition to main content

### Navigation
- **Fixed Header** – Always visible, transparent over hero images
- **Mobile Menu** – Full-screen glassmorphism overlay with animated links
- **Active States** – Underline indicator for current page
- **Scroll Effect** – Header gets subtle blur/background when scrolling

### Responsive Design
- **7-Tier Breakpoint System** – Optimized for every screen size
- **Touch Optimized** – Large tap targets, no hover-dependent interactions
- **Fluid Typography** – Text scales smoothly from mobile to desktop

### Performance
- **Lazy Loading** – Images and videos load as you scroll
- **Code Splitting** – Each page loads independently
- **WebP Images** – Optimized formats for fast loading
- **Preloaded Critical Assets** – Hero image loads instantly

### SEO & Social Sharing
- **Meta Tags** – Optimized title, description, and keywords
- **Open Graph** – Beautiful previews when shared on social media
- **Structured Data** – Schema.org markup for Google
- **Sitemap** – Auto-generated for search engines
